## ⚡ Quick Start in 3 Lines (or click [Open in Colab](https://colab.research.google.com/github/wysking/postgrad-study-engine/blob/main/demo.ipynb) for zero-install run)

```sh
git clone https://github.com/wysking/postgrad-study-engine.git
cd postgrad-study-engine
python -m scripts.study demo --vault ../study-demo
```

Open `../study-demo/reports/demo.html` to view the full report shown above (runs on the Python 3.12 standard library—zero third-party dependencies, no API key required).

## 🧩 Why Postgrad Study Engine?

| Dimension | Ordinary AI Chat Threads | Traditional Flashcards (Anki) | Postgrad Study Engine |
| :--- | :--- | :--- | :--- |
| **Long-term Memory** | Lost across scattered chat threads | Isolated front/back cards without reasoning history | Append-only Git ledger + auto-updated `learner_context.md` profile |
| **Capture Friction** | Manual note-taking breaks study flow | High card-creation overhead for math/proofs | Frictionless `save_study_record` during chat—brief or full derivation |
| **Spaced Repetition** | None—you only review what you remember to ask | Self-graded buttons that ignore hints vs. solo solving | Distinguishes **solo solves** from **assisted fixes** with half-life decay & optional **FSRS** |
| **Data Ownership** | Locked inside one vendor's chat UI | Siloed deck database | **Public Core + Private Git Vault**, works via local CLI or serverless cloud sync |
