> **AI chat tutors forget your weak spots the moment you open a new thread, while traditional flashcards (Anki) flatten multi-step derivations into rote front/back cards.**  
> Postgrad Study Engine archives every real problem-solving exchange, hint, and mistake in a private Git ledger—powering **FSRS / half-life forgetting curves** and periodic learner profiles so your AI tutor remembers what you actually know.

## ⚡ Quick Start in 3 Lines (or click [Open in Colab](https://colab.research.google.com/github/wysking/postgrad-study-engine/blob/main/demo.ipynb) for zero-install run)

```sh
git clone https://github.com/wysking/postgrad-study-engine.git
cd postgrad-study-engine
python -m scripts.study demo --vault ../study-demo
```

Open `../study-demo/reports/demo.html` to explore the full dashboard shown above (Python 3.12 standard library only—zero third-party dependencies, no API key required).

> ⭐ **If you want your AI tutor to remember your derivation bottlenecks and forgetting curves across sessions, consider giving this repo a Star!**

## 🧩 Why It Beats Chat History & Traditional Flashcards

| Dimension | Ordinary AI Chat Threads | Traditional Flashcards (Anki) | Postgrad Study Engine |
| :--- | :--- | :--- | :--- |
| **Long-term Memory** | Lost across scattered threads | Isolated cards with no derivation history | Append-only Git ledger + auto-updated `learner_context.md` |
| **Capture Friction** | Manual notes break study flow | High card-creation overhead for proofs | Frictionless `save_study_record` preserving hint sequences & fixes |
| **Spaced Repetition** | None—review only what you remember | Self-graded buttons ignore hints vs. solo work | Separates **solo solves** from **assisted fixes** with half-life / **FSRS** |
| **Data Ownership** | Locked inside one vendor's chat UI | Siloed local deck database | **Public Core + Private Git Vault** in plain JSON/Markdown |
