This is a file-based allocation, not a choice of either licence for every file.
For MIT material, keep copyright and permission notices. For CC BY material,
credit the contributors and source project, retain supplied notices and the
licence link, and indicate modifications as required by the legal code.

https://creativecommons.org/licenses/by/4.0/legalcode.txt.

The artwork's documented origin is `docs/assets/README.md`: generated public
concept artwork with no private reference image or learning data supplied.
This records that published provenance without claiming new third-party rights.

textbooks, paid courses, scans, question banks, photographs, or official source
works. Compact references or hashes do not extend those rights. The public
Core contains fictional examples; personal learning records belong outside it.

it changes no Python code, schema, protocol, or fictional example.
