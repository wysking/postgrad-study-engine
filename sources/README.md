# Sources

Track source identity, page, edition, and local path here when a knowledge unit comes from a book, question, photograph, or official notice.

Keep large raw files under ignored local directories such as `sources/raw/` or `sources/private/`. Do not commit complete paid course or textbook scans. A source record should preserve enough provenance to re-open the original locally without copying the entire work into the repository.

Compact mobile handoffs, unresolved items, and archive receipts belong in the private Vault, not in this public Core. Durable validated events belong in `events/`; requests remain pending until explicitly receipted. See `../docs/MOBILE_DESKTOP_WORKFLOW.md`.
