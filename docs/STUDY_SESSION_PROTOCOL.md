# Study session protocol

This is a reusable teaching contract for a structured study session. Personal
subject priorities and schedules belong in a private Vault.

## Session start

Read the current Vault status, the relevant subject note, and only the compact
state and source records needed for the session. Ask for the actual time budget
before assigning a substantial workload.

```text
subject:
topic or printed range:
available time:
activity: learn / recall / solve / review / timed practice
answer policy: hints first or explanation first
special goal:
```

## Teaching loop

```text
minimum explanation
→ learner reconstructs or answers
→ diagnose the exact failure mode
→ one or two targeted variants
→ closed-book confirmation
→ compact event and next action
```

Do not promote mastery because an explanation was read, recognized, or agreed
with. Keep comprehension, recall, independent solving, transfer, delayed
recall, speed, and confidence as separate signals.

Hints should be graduated: restate the target, point to a relevant condition,
give a smaller subproblem, give a partial route, then explain fully after an
attempt.

## Recording boundary

Record only structured evidence: subject, unit, activity, source reference,
result, response mode, assistance level, time, confidence when known, and next
action. Do not record a full chat transcript. No answer evidence means no
attempt event.

Close by stating what was demonstrated, the exact unresolved issue, what is due
next, and which facts still require source verification.
