# 研究指标与报告契约草案

状态：设计提案。这里只定义可复算的描述量，不计算思维能力总分，不把偏好、能力表现与长期潜力混合。数据不足时输出研究缺口。

## 1. 统一统计边界

一次 attempt 是一个作答样本；一次观察的多个片段、多标签、多知识单元不能增加全局样本量。同一题重复提交和同一诊断的多次修订也不增加独立样本。单元报告可以各自引用同一多单元作答，汇总时必须按 event ID 去重。

每项输出至少包含：`metric_id`、定义版本、时间窗口、所涉任务范围、分子、分母、样本 ID、缺失/排除原因、采集覆盖和限制。比例必须展示 n/N。N=0 时 `value: null`、`status: not_estimable`，禁止零填充、默认 0.5 或推断耗时。

记录“全部已归档作答数”“具有相关字段数”“严格纳入数”三个层次。用户只归档错题时，不得把错题库当作全部练习。没记录自检不等于没有自检；没有延迟复测不等于遗忘；没有实际用时不等于耗时为零。

原始描述可以使用旧记录的 mode/result；严格研究量还需观测范围、反馈顺序和相关暴露已核实。旧事件缺失新字段默认 unknown；不从标题、题型、活动名或系统语气补出资格。

## 2. 指标定义

### M01—M04：入口、独立与提示

| 指标 | 操作定义与分子/分母 | 数据来源与纳入条件 | 缺失、范围与偏差 |
| --- | --- | --- | --- |
| M01 初始方法选择适切率 | n=反馈前第一个明确方法满足问题条件且可通向解的作答；N=初始方法实际被观察且能判适切的作答。可有多个合法方法，不能只认标准解 | `method_choice` 片段、完整题目条件核验、提示顺序、任务方法适用边界 | 未表达入口为缺失；教师先给方法则不纳入。只代表可观察入口，口述多者更容易被采到 |
| M02 观察窗口内首次合格独立完成 | 每个单元/目标报告最早合格成功的 event ID；比例 n=有合格成功的学习历程，N=从首次接触开始确有连续记录且至少给过一次独立验证机会的历程 | attempt 的正确/完整过程/零相关提示，观察上下文的熟悉度、暴露与覆盖；目标先定义 | 开始学习前已有能力、记录起点不明或没有验证机会则不估比例。只可称“首次记录到”，不能冒充人生中第一次会做 |
| M03 经提示完成的比例 | n=完整正确且需要相关提示/解法暴露的作答；N=完整正确、全程辅助条件已知的作答。另报辅助作答数/全部条件已知作答数，含失败 | attempt + 整次上下文；任何局部零提示不能擦除整题辅助 | 条件未知单列。教师优先提示难题、题目难度变化会影响比例，不能直接解释为依赖增强/减弱 |
| M04 提示后恢复推导 | n=明确提示后恢复了原卡住目标的实际步骤；N=存在可观察卡点、相关提示及后续作答机会的片段链。按提示类别分别列，不平均等级 | 卡点片段、intervention、之后的用户步骤与顺序 | 后续没作答属缺失；系统自己完成不算恢复。只说明提示下局部表现，不说明已独立修复或提示的因果效应 |

### M05—M08：错误监控、修复与迁移

| 指标 | 操作定义与分子/分母 | 数据来源与纳入条件 | 缺失、范围与偏差 |
| --- | --- | --- | --- |
| M05 自主发现并纠正错误 | n=揭错/相关提示前用户自己定位并修正最早客观错误的机会；N=确有客观错误、顺序完整可观察且曾留出自主检查机会的错误事件 | 原稿、`first_divergence`、`self_detection`、中性/定向提示的先后 | 事后说“我刚才忘了”不能证明自主发现；只见局部草稿不纳分母。教师打断越早，自检机会越少，必须报告 |
| M06 局部修复后的复测表现 | n=先有同目标合格独立修复，后在预设窗口第一次合格复测中未再现该错误且完成目标；N=具备这条证据链并实际接受复测的诊断单元事件。另列复发数 | 最新合法诊断链 + 修复 attempt + `retest_of` + 同目标/同单元核验 | 仅 hypothesized 不算确认错因；仅辅助成功不算独立修复。没参加复测列未观测/待复测，不能当失败或成功。不能由同单元不相关成功关链 |
| M07 近/远迁移表现 | 分层 n=每种迁移距离下合格独立完整成功，N=该层实际尝试且题义、来源关系、目标、陌生度可核查的任务，保留失败 | `transfer_from`、变化特征、对照任务、真实作答；近迁移与经复核远迁移分开 | `variant`、换数、混合题或跨学科题名不能充当远迁移标签；熟悉度未知排除严格估计。按题族报告，不能合成泛化天赋分 |
| M08 完整推导的独立重建 | n=关键条件和必要推导链均被独立重建且终点正确；N=事先明确检查范围、确有闭卷重建机会且过程可核验的任务 | attempt、reconstruction 片段、固定核对清单、相关提示/解法暴露 | 局部链只能报告局部能力。刚看过标准推导的重建单独列为近期支持条件，不纳严格无提示重建。不能强迫所有常规题提供完整口述 |

### M09—M12：投入、保持、信心与时间

| 指标 | 操作定义与分子/分母或聚合方式 | 数据来源与纳入条件 | 缺失、范围与偏差 |
| --- | --- | --- | --- |
| M09 从首次接触到独立正确的实测投入 | 单个学习历程 T=首次接触到首个预定义合格独立终点期间，可归属的实际学习分钟总和；汇总用各完整历程 T 的中位数，N=完整计时历程数 | 计时器/当时自报实测活动区间；每段唯一 ID；跨题共享时间不得重复分摊 | 只统计做题时间不能称全部学习投入；有漏计或起点未知则不可估计。尚未达到终点为未完成历程，不能丢掉后只比较快者；不拟合生存模型，不把日历天数当学习小时 |
| M10 延迟复测稳定性 | 每个预先声明的实际间隔层：n=首次无提示复测成功，N=该层实际接受且可判定的复测。另报同单元各次结果序列和待复测人数/事件数 | 时间戳差、`retest_of`、期间相关练习/提示暴露、完整结果；与调度“到期时间”分开 | `delayed_days` 不能单独作证。默认描述分层为 [24,96)、[96,192)、[192,360)、[360,+∞) 小时；小于 24 小时另列近期表现。这些不是遗忘模型。期间复习未知只报“间隔后表现”，不称纯保持；重复检验本身也会影响学习 |
| M11 作答前信心与正确性 | Brier=Σ(p−y)²/N；有符号偏差=Σ(p−y)/N；同时列原始 p、y 和 n/N。n 可指高信心错误数，阈值须报告事先定义 | 在反馈和相关提示前获得的 `confidence_before`，p∈[0,1]，y为合格全题正确=1、错误=0；仅同类条件内比较 | 部分正确、未答、反馈后信心和未经核验结果不混入二元校准；缺信心不填。小样本不画看似平滑校准曲线；表达信心的习惯也影响结果 |
| M12 同条件下作答时间变化 | 每个固定题族/难度/辅助/终点层报告实测有效用时的中位数、范围及样本 N；前后窗口同时列 N 与正确率 | 实测 active time、暂停处理规则、题族、是否重复题、任务终点、结果 | 不只选正确题后声称整体更快；需同时列失败与中止。聊天回复延迟不作测量。改了题型、提示或计时方式则分层，不能直接称效率提升 |

M09 的完整投入、M12 的暂停计时和 M11 的信心采集时点，现有 1.0 字段并不足以独自证明。第一阶段允许用极少量人工核验的研究样本，不为了填满表格马上增加所有计时/会话字段。重复遇到实际研究决策需要后，另提最小契约；在此之前相应量显示不可估计。

比例的小样本只描述，不排行或宣称趋势显著。一个学习历程中的多道题相关，不能按独立抽样计算精确置信区间。保留样本 ID、题族、日期、提示条件和缺失覆盖，比添加小数位更重要。

## 3. 思维特征证据等级

| 等级 | 必需证据与表述 | 限制 |
| --- | --- | --- |
| 单次观察 | 一次有来源的具体行为；“在这道题里……” | 不能推到长期习惯 |
| 重复迹象 | 不同题目的多个情境重复出现；注明题族、提示、次数、反例 | 同题重做、同一提示链的多行不算多个独立情境 |
| 暂时性工作假设 | 有重复依据、至少一个可行替代解释、反例检索和可证伪的后续问题 | “可能与……有关”，不写成固定人格或认知缺陷 |
| 相对稳定的特征 | 跨周、跨题型重复验证，包含真正的延迟表现、提示减少后的表现与反证审查；报告精确观察范围 | 不以任意次数阈值宣称心理量表已验证。跨学科泛化需另外直接证据；相对稳定仍可被新证据修订 |

不自动按计数晋级。等级是带理由的研究结论，接受人工核查；不得由内部 mastery 值生成。偏好只按自述记录；优势必须由表现支持；长期潜力在本系统中没有可验证的量化定义。

## 4. 每份报告的可追溯契约

报告保存一个固定版本：`report_id`、`report_kind`、`as_of`、`ledger_commit`、账本与注册表哈希、Core SHA、编码与资格/指标定义版本、纳入窗口、覆盖/缺失。旧报告保留，未来报告链接旧版本说明结论改变的依据；不将后来的判断覆盖到旧时点。

每项实质结论包含：

```json
{
  "claim_id": "fictional-claim-001",
  "kind": "inference",
  "evidence_grade": "working_hypothesis",
  "scope": "one specified task family",
  "text": "Fictional scoped interpretation, not a learner profile.",
  "support_event_ids": ["fictional-attempt-001"],
  "counter_event_ids": [],
  "limitations": ["Fictional missing delayed outcome."],
  "alternative_explanations": ["Fictional task familiarity."],
  "next_validation": "One later unassisted task when normal study reaches it."
}
```

`kind` 固定为 fact / inference / hypothesis / open_question。fact 不能仅引用系统推断；inference/hypothesis 必须写依据、范围和替代解释，不能把诊断置信度当校准概率。无事件的研究缺口用固定快照、查询条件和结果 0 说明，不伪造一个支持事件。仅检查 ID 存在不够，还要核对它是否支持这句话。

| 报告 | 固定回答 | 数据不足时 |
| --- | --- | --- |
| 单次 | 展示了什么；可见的初始思路；最早偏离；如何修正；独立性与未验证项；各项事件 ID | 初始思路未说出则写未观测，不补标准解法 |
| 周期 | 重复出现的局部错误；新增独立证据；同条件推理/提示变化；复发和待复测；纳入分母 | 列研究缺口和正常学习中的下一次观察机会 |
| 跨月 | 重复策略及后续结果；经过验证的局部优势；风险与反例；结论变化；跨题型与延迟覆盖 | 不能生成稳定画像，不用学习偏好填空 |

“策略 A 后续表现较好”默认是相关描述。若要研究干预效果，先定义相近题族、等预算、终点及延迟窗，采用不同新题的交替或随机顺序，报告不平衡与先验知识；不对同一道题先教 A 再教 B 后宣称 B 更优。正常学习优先，不延迟必要教学制造对照。

## 5. 学科比较的边界

数学可以观察入口、条件、推导与重建；英语要映射到语义解码、文本证据、选项排除与延迟词义回忆，不能要求所有英语任务用数学式推导。物理额外核查模型假设、量纲、极限情形与物理解释。共有观察维度只是索引，不是跨学科等值量表。

把共同数学技能与学科应用分别记录，通过经核验的 `transfer_from` 关系研究同一技能在不同任务中的使用。竞赛成绩、对专业的兴趣、先修缺口、投入与学科适配性分开；不能由一个竞赛题、一次物理试学或喜欢推导推出适合某专业。历史学科错归属保留并标注，不为通过枚举而继续错标。
