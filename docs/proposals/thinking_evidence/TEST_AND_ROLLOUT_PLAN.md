# 验收测试与最小发布计划

状态：草案。这里区分“现有实现已测”“草案结构已测”和“未来集成待测”，不得合并成一个完成率。

## 1. 本目录可执行检查

`observation.schema.json` 是独立的新事件 Schema 候选，未被现有 Schema 引用。`fictional_cases.json` 全部为虚构材料，不能进入任何真实账本。`review_check.py` 是离线评审工具，生产代码不导入它，不新增生产依赖。

在隔离评审环境安装 `jsonschema==4.26.0`，执行：

```bash
python docs/proposals/thinking_evidence/review_check.py
python -m unittest discover -s tests -v
python -m scripts.validate_events
```

第一条检查草案 Schema、绑定关系、来源状态、局部引用和线性修订的虚构例；并不证明真实来源可信，也没有测试当前手机入口接受新事件。旧 Core 应明确拒绝新格式，不能靠忽略字段“兼容”。本目录不修改 `VERSION`、生效 Schema、reducer、scheduler、processor 或 CI。

## 2. 新契约的验收矩阵

| ID | 输入/操作 | 必须观察到的结果 | 本草案检查覆盖 |
| --- | --- | --- | --- |
| T01 | 单个真实锚、局部步骤、受提示来源 | 正常接收，来源与提示保留 | 离线虚构例 |
| T02 | 顺序/提示未知 | 可保留 unknown，不产生独立资格 | 结构接收；资格集成待做 |
| T03 | 事后自述获用户确认 | 来源仍是 retrospective，不改当时直接观察 | 离线虚构例；报告语义另审 |
| T04 | 系统推断标为 source_checked | 拒绝；不能伪装用户原始路径 | 离线虚构例 |
| T05 | 老摘要自动升级原稿、教师解法冒充用户 | 老摘要不得直接核查；教师文字不成为用户路径 | 部分结构覆盖；必须人工对照来源 |
| T06 | 字迹歧义未消除却确认错误 | 拒绝已核查状态；保留未核实与最早可确认位置 | 离线虚构例 |
| T07 | 不存在/非 attempt 锚、错题号、错学科、扩大单元 | 整批拒绝，无持久输出 | 离线结构部分；原子性待集成 |
| T08 | bool 代替整数、等级越界、长片段、聊天字段 | Schema 与运行时同样拒绝 | 离线虚构例；未来运行时对照 |
| T09 | 重复局部 ID、未知提示 ID、悬空/未来支持 | 拒绝且不追加 | 离线虚构例；批次未来引用另测 |
| T10 | 合法同链修订、同时间戳、跨锚/过期前驱/分叉/循环 | 只接受合法线性链；最新由链决定 | 部分离线例；完整序列集成待做 |
| T11 | 无关单元复测或自我支持 | 不构成修复/保持证据 | 离线虚构例；目标能力细化待集成 |
| T12 | 仅 activity=variant、远迁移缺变化依据 | 不升级迁移；人工复核距离 | 部分离线例；严格资格待集成 |
| T13 | 局部步骤零提示但整题已给路线 | 保存局部事实，整题仍辅助 | 必须增加手机端到端测试 |
| T14 | 有 delayed_days 但无可验证前次事件/期间暴露 | 不称纯保持；只报间隔后表现或不可估计 | 必须增加资格与报告测试 |
| T15 | 新增任意数量观察及其修订 | attempt_count、能力资格、诊断闭环及排程输入均不凭空增加 | 必须增加新 reducer 的不变量测试 |
| T16 | 混合 1.0/1.1 历史，旧字段缺失 | 完整重放，旧字段 unknown；输入字节不变 | 必须增加迁移/双版本测试 |
| T17 | 同 request/hash 重试、同 event/相同内容、冲突复用 | 幂等或明确冲突，不能制造第二作答 | 复用既有测试并加入新事件批次 |
| T18 | 绑定校验、重建、导出或回执发布失败 | 所有已发布文件一致；失败不称归档 | 复用事务测试扩展混合批次 |
| T19 | 进程争用、被杀、云端新提交/普通 push 拒绝 | 不丢成功事件、不制造永久争用失败；恢复明确 | 复用已提可靠性请求，新增事件加入固定场景 |
| T20 | 成功回执存在但派生文件损坏/缺失 | 幂等回执不被误当作当前投影健康；只读校验后按受控方式重建 | 独立故障演练；不静默改旧回执 |
| T21 | 新格式写入后回退旧读者 | 预检拒绝危险锁回退；可关闭新写入保留兼容读者 | 必须进行发布与回滚演练 |
| T22 | 坏 JSONL、合法 BOM/CRLF/空格前缀 | 坏数据失败；有效旧前缀保持原字节 | 既有硬化请求负责，不重复实现 |

T20 是运行说明与测试缺口：同请求成功回执表示当时提交成功，不保证后来派生文件始终完整。保留已有成功去重语义；必要重建不通过伪造新作答完成。它不等同已证实的生产故障。

## 3. 指标与报告验收

| ID | 场景 | 验收 |
| --- | --- | --- |
| R01 | 0 个合格样本或关键字段缺失 | null + not_estimable + 原因，不能是 0% |
| R02 | 一条观察含多步骤/维度/单元、同题重复上传 | 全局样本按 attempt ID 去重；修订不增样本 |
| R03 | 只有错误题记录、正确题未完整采集 | 明示归档选择偏差，不能报告全体练习正确率 |
| R04 | 事后解释、系统推断和原稿混合 | 事实只能由对应来源支持，逐句核对，不生成完整虚构心理路径 |
| R05 | 提示序列未知、自检发生在揭错之后 | 不纳自主监控或无提示成功分子；缺失不作失败 |
| R06 | 先辅助成功，再独立成功，再延迟失败 | 三条都保留；结论限制为近期能力已有证据、保持不稳定 |
| R07 | 两个合法诊断修订、最新 rejected | 旧结论仍可追溯，当前不当 confirmed 统计 |
| R08 | 报告时点后才到达支持证据 | 旧报告不得引用，回填观察时间不改变当时已知信息 |
| R09 | 时间缺失、暂停未计、计时范围改变 | 不输出学习效率数；按缺失/不同口径分层 |
| R10 | 后验信心、部分正确或未经核验结果 | 不进入二元 Brier；列缺失原因 |
| R11 | 题型难度/提示程度改变 | 不把未分层的前后比例差称思维发展 |
| R12 | 仅偏好自述、单次慢题或单次局部错误 | 拒绝稳定能力/潜力画像，输出局部观察与验证缺口 |
| R13 | 结论带存在但不支持内容的事件 ID | 人工语义审查不通过；ID 存在性测试不能替代支持性检查 |
| R14 | 旧的学科错归属/竞赛整卷自报 | 不重写历史，不当正式限时基线或跨学科适配结论 |

## 4. 人工编码质量和负担试点

从自然学习中产生的普通成功、错误、自我检错、策略变化、近期提示和事后自述各选少量片段，先冻结原始可见材料与原编码，再遮住旧标签重新编码；条件允许时由另一核查者盲看。按来源类别、提示先后、最早偏离与目标匹配分别列分歧和未决项，不能把同一个模型重复输出当作独立效度验证。

记录真正新增的追问次数、额外实测耗时、用户放弃验证的情况。结构不清的部分改成 unknown 或收紧规则；如果对普通学习的打断明显，先减采集步骤，不能为研究强加每题表单。此试点只验证可用性和编码一致性，不证明量表效度或学习收益；不设未经证实的“准确率达标”数字。

## 5. 分阶段提交与采用门槛

| 批次 | 最小范围 | 采用前必须通过 |
| --- | --- | --- |
| A 前置可靠性 | 已有资格、闭环、到期、学科、幂等/恢复、并发整改 | 对修复后精确 head 的反例与正例、完整套件、隔离旧账本重放；单独评审与发布 |
| B 契约读者 | 新事件类型及混合版本校验；不开放新写入 | T01—T12/T16/T17、Schema—运行时对照、旧账本兼容、明确锁版本语义 |
| C 观察写入 | 复用 save_session_result，追加观察与修订，提示来源采集 | T13—T22、同批锚关联、事务/并发、输入哈希与回执一致；完整套件 |
| D 只读报告 | 指标口径、固定快照、事件引用、缺失与等级 | R01—R14、人工来源核对、负担试点；数据不足的默认回退 |

B/C/D 不改调度权重、不新增隐式复习、不从观察生成 mastery 成功。跨学科新 subject/正式考试合同与历史归属修订另行评审，不能夹带在本契约中。每批提交写明未实施项，评审后发 Core 版本，再由单独 Vault 锁 PR 采用；文档存在、虚构测试通过或 CI 绿色都不是上线证据。
