# Public repository artwork

`social-preview.png` is an AI-generated editorial cover for the repository,
not a screenshot or measured learner curve. Its visible disclaimer and
illustrative-curve label are intentional. Both READMEs use descriptive alt text.

- Current encoded size: 885,108 bytes; dimensions: 1774 × 887 (2:1).
- Generated with the built-in image-generation tool; no private reference
  image, real learning record or account data was supplied.
- PNG was losslessly repackaged, with byte-for-byte equality of decoded RGBA
  pixels checked against the selected generated output. No image pixels were
  changed during packaging. The original draft is retained outside the repo.
- This is a project asset. Committing it and referencing it from README do not
  set GitHub's Social preview; that separate setting must be saved and verified.

GitHub's [official preview requirements](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)
allow PNG/JPG/GIF under 1 MB and recommend a 2:1 image, ideally at least
1280 × 640. The selected asset meets these size and dimension requirements.

## Initial generation prompt

Create a polished GitHub repository social preview marketing image for an open
source learning engine. Output one 1280×640 pixel PNG, aspect ratio exactly 2:1,
ideally under 1 MB using mostly flat colors. This is a text-led editorial
technology poster, not a website mockup. Off-white background, dark midnight-navy
bold Chinese sans-serif typography, restrained mint and blue accents, generous
whitespace and at least 64-pixel safe margins. Crisp professional typesetting.
Main large headline at left, rendered verbatim in two lines: “考研 AI 私教” and
“拟合你的遗忘曲线”. Small top label verbatim: “postgrad-study-engine”. Smaller
subheading verbatim: “长期档案 · 错因追踪 · 先修探针”. Bottom disclaimer, clearly
readable verbatim: “实验模型 · 真实人群校准尚未验证”. On the right, a clean abstract
descending curve with a couple of circular nodes and a rising feedback stroke,
no axes, no numerical values; label this tiny graphic “示意 · 非实测”. The graphic
is illustrative only and must not resemble measured learner data. No screenshots,
no fake metrics, no score-gain claims, no mascots, no stock photos, no OpenAI
logo, no QR codes, no additional text. Distinctive, calm and credible, optimized
for readability as a small social card.

## Final edit prompt

Prepare this exact typographic poster for GitHub Social Preview. Preserve every
Chinese/English character, hierarchy, legibility and the exact composition.
Change only the surface rendering: make background 100% pure solid white with
absolutely no noise, paper grain, shadows, gradients or texture; make all letters
and graphic shapes perfectly flat clean solid-color vector-style areas. All
circle fills should be a single very pale mint or blue, no gradients. Curves and
lettering keep the same dark navy / bright blue / mint colors. Retain all
disclaimers including 示意 · 非实测 and 实验模型 · 真实人群校准尚未验证. Deliver a
clean 2:1 PNG suitable for GitHub, ideally exactly 1280 by 640 pixels and strictly
under 1 MB by keeping flat graphics and no noise. Do not add, remove, translate
or change any text, shapes or meaning.
