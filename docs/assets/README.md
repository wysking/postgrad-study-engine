# Public repository artwork

`social-preview.jpg` is the selected editorial cover for Postgrad Study Engine.
It pairs a charcoal background and layered paper archives with a vermilion tab.
Both READMEs reference this image and describe its visible content in alt text.

The image contains exactly three text groups:

- `POSTGRAD STUDY ENGINE`
- `考研 AI 私教`
- `学习档案 / 记忆拟合 / 错因诊断`

## Asset properties

- `social-preview.jpg`: JPEG, 1280 × 640 pixels (2:1 standard GitHub Social Preview size), resized from the original 2:1 editorial banner composition without adding new elements.
- `demo.png`: PNG screenshot of the real `reports/demo.html` output generated by running `python -m scripts.study demo` (`examples/courses/fictional-14-days.json`).
- No private reference image, real learning record or account data was supplied.

## Repository setting

Committing the file and referencing it from README do not configure GitHub's
Social preview. Upload this JPEG separately in repository Settings → General →
Social preview, save it, and verify the resulting settings page.
